ふたりの毎日を、もっと特別に。

ふたりだけの日々を残すための、専用SNS

デモを見る ログイン不要ですぐに試せます

できること

  • 投稿

    今日あったことを、写真と一緒に残せます。ふたりだけのタイムラインに積み重なっていきます。

  • カレンダー

    会った日・記念日・これからの予定を1つのカレンダーで管理。会った日数は自動で数えます。

  • 統計

    付き合って何日目か、会った日数、投稿数。ふたりの歩みを数字で振り返れます。

  • 思い出し

    1ヶ月前・半年前・1年前の投稿を、ホームでそっと差し出します。過去の記録が意味を持ちます。

技術構成

個人開発ですが、複数ペア・複数人が同時に使える前提で設計しています。 いくつかの設計判断を紹介します（詳細は docs/decisions.md）。

  • Expo (React Native Web) + Expo Router
  • Hono + oRPC（型安全なAPI層。Zodスキーマ）
  • Cloudflare Workers / D1 / R2
  • Drizzle ORM
  • TanStack Query

認可を1箇所に集約する

全ての手続きは ctx.coupleId だけを使い、引数として coupleId を受け取りません。 他ペアのIDを送りつける経路そのものを作らない設計にし、認可の書き忘れが起きる余地を無くしました。

記念日・予定・会った日を1テーブルに統合する

種類ごとにテーブルを分けず、kind 列を持つ1つの events テーブルにしました。 カレンダー表示・射影計算（繰り返す記念日）のロジックを1箇所にまとめられます。

「去年の今日」を「思い出し」に一般化する

「去年の今日」だけだと使い始めて1年間は何も表示されません。 1ヶ月前 → 半年前 → 1年前の順に探し、無ければ過去投稿からランダムに1件出す設計にし、 使い始めた翌日から機能するようにしました。

デモは未認証・閲覧専用

ログインの壁で離脱するのを避けるため、専用のデモペアを1組用意し、 未認証アクセスはそのペアのデータだけを読み取り専用で返します。 書き込みの拒否をサーバ側の1箇所（認可ミドルウェア）に集約し、UI側の実装漏れが本番データに波及しない設計です。
