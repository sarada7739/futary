# 033: 複数画像を横にスライドする

## 目的

**X のように、複数の画像を横一列に並べて指で送れるようにする。**

人間の要望（X の画面のスクリーンショット2枚つき。
1枚目は右にまだ続きがあることが見えている状態、2枚目は送ったあとの状態）。

**031 で私が決めた2つを覆す。**

| 031 | 033 |
|---|---|
| 2枚以上は正方形グリッド。1行に2枚 | **横一列。指で送る** |
| ライトボックスは左右のボタン。スワイプにしない | **スワイプにする。ボタンも残す** |

## 0. 最初に確かめること（B）

**私は「ライブラリが要らない」ことを確かめていない。**

| | |
|---|---|
| **私が開いて確かめた** | `react-native-gesture-handler` と `reanimated` は `apps/app/package.json` の依存に**無い** |
| **確かめていない** | `react-native-web` 0.21.1 で `ScrollView` の `horizontal` + `pagingEnabled` が**実際に効くか**（A のツリーに `node_modules` が無い） |

**先に効くことを確かめてから進める。**

1. `ScrollView horizontal pagingEnabled` が Web で効くか
2. 効かないなら、**CSS の `scroll-snap` で代替できるか**
3. **どちらも駄目なら止めて A に上げる。**ライブラリを入れる判断は
   このタスクに含まれていない

**「たぶん動く」で作り始めない。**

## 1. 私の 031 の理由づけが間違っていた

031 に**「スワイプにしない。ジェスチャライブラリは `requirements.md` 5節で
スコープ外のまま」**と書いた。

**`requirements.md` 5節がスコープ外にしていた理由は、
ジェスチャライブラリの導入が要ることだった。**
**ページング付きの `ScrollView` には要らない**（B の指摘）。

**理由が成り立たないのに、結論だけ残っていた。**

## 2. 一覧の見え方

- **1枚のときは、いまのまま**（031 から変えない。**既存の見え方を変えない**）
- **2枚以上は横一列。指で送る**
- **次の画像の端を見せる。**これが無いと、**続きがあることに気づかれない**
  （人間が渡した1枚目のスクリーンショットは、まさにその状態である）

### ドットのインジケータを置かない

**最大4枚である。端が見えていれば、続きがあることは分かる。**

**要素を増やさない。**「何枚目か」を数字でもドットでも出さない。
**ライトボックス（全画面）では出す**（下記）。**そこでは端が見えないため。**

## 3. ライトボックス（017・031）

**スワイプで送れるようにする。ボタンは残す。**

- **一覧で横スワイプを覚える。同じものを別の操作にしない**
- **ボタンを消さない。**PC からマウスで見る人が送れなくなる。
  **031 で入れたものを捨てない。**あれはデスクトップの経路になる
- **何枚目かを出す**（`2 / 4`）。全画面では次の端が見えないため
- **閉じる導線は 017 のまま3つ持つ。**
  **スワイプで閉じる操作を足さない**（横の送りと取り違える）

## 4. `requirements.md` 5節を2行に分ける

いまは1行にまとまっている。

> 画像のピンチズーム・**スワイプ操作** | ジェスチャライブラリの導入が要る。
> 保存解像度が長辺1600pxなので深く拡大しても粗くなる | 次フェーズ

**理由が違うものを1行にまとめていた。**

| | 扱い |
|---|---|
| **ピンチズーム** | **スコープ外のまま。**ジェスチャライブラリが要る。**1600px では深く拡大しても粗い** |
| **横スワイプでの送り** | **033 で実装する。**ライブラリは要らない |

**「1600px で粗くなる」はピンチズームにしか効かない。
送りには関係が無い。**まとめたせいで、**片方の理由がもう片方に効いているように
読めた。**031 で私がそう読んだ。

## テストで証明すること
- **1枚のときの見え方が変わっていない**（031 から2回連続で守る）
- 2枚以上で横に送れる
- **次の画像の端が見えている**（続きがあることが構造として出ている）
- ライトボックスで**スワイプとボタンの両方**が効く
- **`react-native-gesture-handler` / `reanimated` を追加していない**
  （`package.json` の差分で確かめる）

## 確認観点
- **続きがあることに気づくか**（人間の実機確認。**これが本体である**）
- 送ったあと、**元の位置に戻れるか**
- ライトボックスの**閉じる操作と、送る操作が混ざらないか**
- PC（マウス）で送れるか
