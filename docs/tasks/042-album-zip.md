# 042: アルバムをまとめてダウンロードする

## 目的

**人間の指示（041 で「ダウンロード機能はほしい」）。アルバム 1 つ（タイムラインを含む）の写真を 1 つの ZIP で保存する。**

041 で 1 枚ずつは保存できる。**41 枚を 41 回押すのは保存ではない。**

## 0. 方式（A が先に決めた）

**ブラウザで ZIP を組む。Worker を通さない。**

| 方式 | 見送る理由 |
|---|---|
| Worker が R2 から読んでストリームで ZIP を返す | 無料枠の Worker は CPU 10ms/リクエスト。ZIP は圧縮しなくても CRC32 を全バイトに掛ける（25MB で 100ms 超）。**無料で運用する**（`requirements.md` 5節）を壊す |
| **ブラウザで `fetch` → ZIP（無圧縮）→ `<a download>`** | 画像は既に署名付き URL でブラウザに来ている。**足すのは ZIP の組み立てだけ** |

- ライブラリは **`fflate`**（`zipSync` の `level: 0`。依存 0・約 8KB）。**A は `react-native-web` で `fflate` が動くことを確かめていない**（B が段階0で確かめる）
- **`fetch` には R2 の CORS（GET・アプリのオリジン）が要る。**`r2-cors.json` にローカルは入っている。**本番オリジンが入っていることを人間に確かめてもらってから着手する**（016 の人間パート。無ければ本番でだけ失敗する）
- JPEG は圧縮しない（`level: 0`）。圧縮しても縮まず、CPU だけ使う

## 1. 上限

**1 回の ZIP は 100 枚まで。**100 枚を超えるアルバムは**古い順に 100 枚ずつ分けて保存する**（「1〜100 枚目」「101〜200 枚目」…のボタンを並べる）。

- 根拠: 長辺 1600px の JPEG は 1 枚 300〜600KB。100 枚で 30〜60MB。**iPhone の Safari のタブがこれ以上を Blob に持つと落ちることがある**。
  **段階0で実測する**（下記）。落ちるなら 50 に下げる。A の手番は要らない（数だけ変える）
- `photo.list` を `limit` 60 で辿って集める。**ビューアと同じ手続きで、専用の手続きを足さない**

## 2. 段階0（B。先に確かめる。結果を `artifacts/042/spike.md` に）

1. `fflate` が `react-native-web` のバンドル（Expo Web エクスポート）で動く
2. **iPhone の Safari で 100 枚（本番相当の JPEG）を `fetch` → `zipSync` → `<a download>` が落ちずに完走する**（人間の実機。落ちたら 50）
3. 本番の R2 の CORS にアプリのオリジンが入っている（人間に `r2:cors:list` を頼む）

**3 が無ければ着手しない**（本番で確かめられない機能を作らない）。

## 3. 画面

- 詳細（041 の `album/[id]`）のヘッダーに**「保存」**。押すと確認シート: 「38 枚を ZIP で保存します（約 15MB）」→「保存」。
  概算は枚数 × 400KB（実測で直す）
- 進捗: 「12 / 38」の 1 行 + `ActivityIndicator`。**途中で閉じられる**（`AbortController`。閉じたら Blob を捨てる）
- 失敗: 1 枚でも取れなければ **その枚を飛ばして続け、最後に「2 枚は保存できませんでした」**（全部やり直しにしない）
- ゲストも押せる（041 の 1 枚保存と同じ理由）
- ファイル名: `futary-{アルバム名を安全な文字に}-{YYYYMMDD}.zip`。タイムラインは `futary-timeline-{YYYYMMDD}.zip`。**日本語はそのまま**（ブラウザの `download` 属性は UTF-8 を通す。`/` `\` `:` 等だけ `_` に）。
  中の各ファイル名は 041 の `filename`（`futary-YYYYMMDD-{imageId}.jpg`）と同じ規則

## 4. やらないもの

| | 扱い |
|---|---|
| Worker 側の ZIP | しない（0節） |
| 圧縮 | しない |
| 100 枚超を 1 つの ZIP に | しない（1節） |
| 選んだ写真だけ ZIP | しない。アルバム単位。要るなら 041 の選択モードに「保存」を足す |

## 5. テストで証明すること

| # | 何を | どこで |
|---|---|---|
| T1 | 100 枚を超えると分割のボタンが出る（101 枚 → 2 つ） | `apps/app` |
| T2 | ZIP の中身: 枚数・ファイル名の規則（`fflate` の `unzipSync` で開いて数える） | `apps/app` |
