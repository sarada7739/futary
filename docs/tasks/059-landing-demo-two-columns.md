# 059: LP の「さわってみる」を 2 列に（左にスマホ・右に案内）・AI まとめの帯の写真を外す

## 目的

**人間の指示（2026-09-17）。**

1. AI まとめの帯（節 5）の右の写真（`hands-cafe.jpg`。重ねた手とコーヒー）が合わない → **消す**
2. 「さわってみる」（節「demo」）はスマホが中央に 1 つで**左右が寂しい** → **スマホを左に、右に見出し・触り方の案内・ボタンを置いて幅を使う**
3. 説明の文言を `ゆいとれんのデモです。` → **`デモ画面です。`** に
4. 節 3（ふたりのこと、置き場がほしかった。）の 3 枚のカードは写真がカードの下端に貼り付いている → **写真の下に白の余白を入れる**

LP は JS 無しのまま（054 の 0節 #13）。写真は足さない。

## 0. 決めたこと（A）

| # | 論点 | 決定 | 理由 |
|---|---|---|---|
| 1 | AI まとめの帯 | 右の `<img class="ai-band-photo">` を消す。帯は**地の絵（`ai-network.jpg`）+ 中央の文字だけ**。`min-height: 200px` はそのまま（文字だけで帯が薄くならない）。`.ai-band-photo` の CSS（PC・720px 未満の両方）も消す | 写真が合わない（人間の判断）。代わりの写真は置かない |
| 2 | `hands-cafe.jpg` | `apps/landing/assets/hands-cafe.jpg` を**消す**。`docs/sample/landing/hands-cafe.jpg`（原本）は残す（人間の素材置き場。A が README の用途を「未使用」に直した） | 配信しないものを置かない。原本は人間のもの |
| 3 | 「さわってみる」の組み方 | **2 列。左にスマホ（`.phone`。527×791 のまま）、右に文字の列。** `.container`（960px）の中で `display: grid; grid-template-columns: 527px 1fr; gap: 40px; align-items: center`。右の列は上下中央 | 左右の余白をなくす。スマホの倍率・絵は 056 のまま動かさない |
| 4 | 右の列の中身（上から） | (a) `<h2 id="demo-heading" class="serif">さわってみる</h2>`（**左寄せ**。今の中央寄せをやめる）/ (b) **`デモ画面です。投稿は見るだけで、書き込みはできません。`**（`.demo-lead`。文言を変える: 「ゆいとれんのデモです。」→「デモ画面です。」。左寄せ・上下の負のマージンを外す）/ (c) **触り方の案内**（#5）/ (d) `<a class="btn btn-primary" href="/app/">自分たちで始める</a>`（今の `.demo-more` のリンクをボタンに。文言は同じ、`→` は付けない） | 見出しと説明が枠の上にあると右の列が空く。列の中に全部入れる |
| 5 | 触り方の案内の文言 | 小見出し **`枠の中を、そのまま触れます`**（`<h3>`）と 3 行の箇条書き（`<ul class="demo-guide">`）。**この 3 行以外は足さない**（054 の 3 節と同じ）: <br>・`ホーム` — ふたりの日数と、機能の入口 <br>・`カレンダー` — 記念日・予定・会った日を、ひとつの月表示で <br>・`タイムライン` — 写真と言葉の投稿と、リアクション <br>（タブの名前は `<strong>`。「—」の後は 1 行。行の頭に記号や絵は置かない） | 訪問者が「動くもの」だと気づかない。タブの名前は下のタブバーと同じ語にする（054 の節 4 の文言と食い違わせない） |
| 6 | 768px 未満 | **今のまま節ごと `display: none`**（056 の 0節 #5）。右の列だけ出す分岐は作らない | 案内は枠を触る前提の文で、枠が無い画面に出すと嘘になる。スマホは「ログインせずにデモを見る」に任せる |
| 7 | 768〜960px | grid の左の列は 527px で固定なので、右の列が 200px 前後まで細くなる。**そのままでよい**（文字は折り返す）。960px 未満で 1 列に落とす分岐は作らない | 分岐を増やさない。767px で消える |
| 8 | 見出しの並び順（見出しの階層） | `h2` さわってみる → `h3` 枠の中を、そのまま触れます。他の節の `h2` と同じ階層 | 054 T3（見出しの階層）を崩さない |
| 9 | OGP・sitemap・`/tech` | 触らない | 節の中の並びが変わるだけ |
| 10 | 節 3 の写真カード（`.cards-3 .photo-card`） | **写真の下に 22px の白の余白**（左右・上と同じ）。`.photo-card` の `padding` を `22px` の四方に、`img` の `border-radius` を **四隅 14px** に（今は上 2 隅だけ角丸で下端はカードの縁に貼り付く）。節 6・7 の `.cards-2 .photo-card`（ほしいもの・思い出・アルバム）も**同じ**にする（同じクラスで、片方だけ貼り付いていると揃わない） | 写真がカードの下端に貼り付いていて窮屈（人間の判断）。カードの中に写真が「置いてある」形にする |
