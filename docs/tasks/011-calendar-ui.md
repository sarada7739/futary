# 011: カレンダーUI

## 目的
月表示のカレンダーで記念日・予定・会った日を見て、登録できるようにする。

## 変更対象ファイル
- （新規）`apps/app/app/calendar.tsx`
- （新規）`apps/app/components/month-grid.tsx`
- （新規）`apps/app/components/event-form.tsx`
- `apps/app/app/(tabs)/index.tsx` — ホームからカレンダーへの導線

## 実装内容
- 月表示のグリッド（日〜土）。前月・翌月へ移動できる
- イベントのある日にマーカーを表示する。**種別ごとに色を変える**
  - 記念日 / 予定 / 会った日 が一目で区別できること
  - 色はトークンから取る。生の16進カラーを書かない
- 選択された日のイベント一覧を、カレンダーの下にカードで表示する
- 追加ボタンからイベントを登録する
  - 日付、タイトル、種別（記念日 / 予定 / 会った日）
  - 記念日を選ぶと `repeat_yearly` が自動で `true` になる
- 既存イベントの編集・削除
- カレンダーライブラリは**入れない**。月グリッドは自前で組む
  （React Native Web で動くカレンダーライブラリの選定と検証に時間を取られるため。
  月グリッドの描画自体は日付計算さえ正しければ単純）
