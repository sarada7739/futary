# デザイン素材

`docs/sample/` は**素材の原本置き場**である。ここから切り出して
`packages/ui/assets/` や `apps/app/assets/` に配置する。原本は加工しない。

**素材を置いたら、置いたツリーで追跡に入れる。**
人間はどの worktree に置くか意識しない。置きっぱなしで未追跡のまま残ると、
**別の役が自分のツリーから同じファイルをコミットしたとき、
置いた側で未追跡ファイルとの衝突が起きて `git pull` が止まる。**
実際に `風景/` の6枚で起きた（内容は同一だったため実害なし）。

### ファイル名から中身を判断しない

`man1.jpg` は当初 `woman2.jpg` という名前だった。**A が中身を見ずに付けた**
（PR #29）。**実際には男性のポートレートである。**

この誤りから「アバターは女性2人なのに投稿写真は男女のカップルで食い違う」という
論点（L55）が生まれ、**人間に「男性のポートレートを1枚追加で生成してほしい」と
勧めるところまで行った。**素材は最初から揃っていた。

`風景/` も同じで、**6枚中4枚には男女2人が写っている。**フォルダ名は風景だが
中身は違う。

**素材を受け入れるときは1枚ずつ開く。**名前は中身の情報ではない。

### `UlQMVnAB.png` は素材ではなく見本である

020 の受け入れ中に人間が置いた。**ホーム機能パネル7枚の絵姿が、この1枚に揃っている。**

**切り出さない。見て、同じものを描く。**理由は4つ。

| | |
|---|---|
| **透過が無い** | 拡張子は `.png` だが**実体は JPEG**（先頭が `ffd8ffe0`。他の4枚は `89504e47`）。**JPEG はアルファチャンネルを持てない**（他の4枚はいずれも colortype 6 = RGBA）。背景のクリーム色がアイコンに付いてくる |
| **線画に JPEG の劣化が乗っている** | 線の周りにリンギングが出る。**淡い背景の細い線で最も目立つ** |
| **大きさが足りない** | 全体で 1024×1024。アイコン1個あたり 120px 前後しかない。下記「切り出しの手順」の**表示サイズの3倍**を満たすのは 32pt 表示までで、それを超えると届かない（他の4枚は 1536〜1923px ある） |
| **既存のタブアイコンと様式が違う** | 塗りと差し色（ピンク）が入っている。カレンダー・タイムラインは**単線・単色・`tintColor` 追従**で描き起こした。切り出すと**同じ画面の中に2つの様式が混ざる**（ホームではパネルとタブが同時に見える） |

**人間に再エクスポートを頼まない。**B から一度「透過 PNG での再エクスポートが要る」と
伝えているが、**取り消す。**再エクスポートで直るのは1つ目だけで、**残る3つは直らない。**
**直らないものを直してもらっても、結局使わない。**

`woman2.jpg` と同じ形である（上記）。**素材の側の問題に見えて、
実際にはこちらが素材の使い道を決めきれていない。**人間の手を借りる前に、
**借りずに済むかを先に見る。**

**見本としては十分に効く。**7枚がそれぞれ何のアイコンかは、この1枚で確定した。
**足りないのは解像度と透過であって、絵ではない。**

### カレンダー・タイムラインのタブアイコンだけ素材に無い

`dnUunrHG.png` / `6sj6V6ve.png` / `i0nWVbG4.png` / `xVR7MWn8.png` を全部見たが、
**カレンダーに読めるものは無い**（B の調査。A も `dnUunrHG.png` を確認）。
**タイムラインに読めるものも無かった**（020。同じ4枚を確認済み）。

`xVR7MWn8.png` の「12」の丸は**使わない。**
「カレンダー」ではなく**日付バッジ**に読める。24px では意図が伝わらない。
この節の下で既に「使わないもの」に分類してある（通知用で対応機能が無い）。

**SVG で描き起こす。**既存4つのスタイルが単純なので、揃えられる。

| 揃える点 | |
|---|---|
| 線 | **単線・塗りなし。**線の太さを既存4つと揃える |
| 角 | **角丸。線端も丸** |
| 色 | 単色。`tintColor` で選択状態に追従できること |
| 形（カレンダー） | 角丸の四角＋上に短い脚2本＋中に横線1本 |
| 形（タイムライン） | 長さの違う横線3本（フィードらしさを出す。数字やアイコンは入れない） |
| **入れないもの** | **日付の数字（カレンダー）。**24px で潰れる |

**カレンダー・タイムラインの2つが、素材から切り出さないアイコンになった。**
以降もし同じことが起きたら、ここに追記する。

見本は**色と角丸の目安**としてだけ使う。

**素材があることは、機能を足す理由にならない。**
スコープ外の判断は「実装が重いから」ではなく「MVP に要らないから」で下している。
素材が揃ったことはその判断を変えない。

## 切り出しの手順

原本は**スプライトシート**であり、そのままアプリに載せない。

- 個別の要素に切り出し、**表示サイズの3倍程度**まで縮小してから配置する
  （タブアイコンなら 24pt 表示 → 72px 前後）
- 原本は 1500〜1900px あるため、縮小せずに載せると初回表示が遅くなる
- 透過（アルファチャンネル）を保ったまま PNG で保存する
- 切り出したファイルは `packages/ui/assets/`（複数箇所で使うもの）または
  `apps/app/assets/`（アプリ固有のもの）に置く

アイコンの色は**素材に焼き付いている**。トークンの色と食い違う場合は、
`docs/architecture.md` 7節の値に合わせて調整するか、
単色のものは `tintColor` で着色できる形に加工する。
`conventions.md` 4節の「生の16進カラーをコンポーネントに書かない」は
画像アセットには適用されないが、**素材の色とトークンがずれたまま放置しない**。
