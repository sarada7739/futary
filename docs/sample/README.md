`packages/ui/assets/` や `apps/app/assets/` に配置する。原本は加工しない。

**素材があることは、機能を足す理由にならない。**
スコープ外の判断は「実装が重いから」ではなく「MVP に要らないから」で下している。
素材が揃ったことはその判断を変えない。

## 切り出しの手順

原本は**スプライトシート**であり、そのままアプリに載せない。

- 個別の要素に切り出し、**表示サイズの3倍程度**まで縮小してから配置する
  （タブアイコンなら 24pt 表示 → 72px 前後）
- 原本は 1500〜1900px あるため、縮小せずに載せると初回表示が遅くなる
- 透過（アルファチャンネル）を保ったまま PNG で保存する
- 切り出したファイルは `packages/ui/assets/`（複数箇所で使うもの）または
  `apps/app/assets/`（アプリ固有のもの）に置く

アイコンの色は**素材に焼き付いている**。トークンの色と食い違う場合は、
`docs/architecture.md` 7節の値に合わせて調整するか、
単色のものは `tintColor` で着色できる形に加工する。
`conventions.md` 4節の「生の16進カラーをコンポーネントに書かない」は
画像アセットには適用されないが、**素材の色とトークンがずれたまま放置しない**。
