# 068 追補 3: スクロールで斜めから正面へ

`docs/tasks/068-phone-3d-tilt.md` の「追補 3」（曲線と始めの角度は #475 で決まった）。画面は `artifacts/068/stage4/`（`stage3/` は追補 2 で使ったので、分けた）。#471（追補 2）のマージ（main e65ace0）の記録もこの PR に含める。

## 実装

`apps/landing/js/tilt.mjs`（純粋な関数）:

- `scrollProgress(top, stageHeight, viewportHeight)`: ステージの上端がビューポートの下端で 0、スマホの中心がビューポートの中心で 1。外は 0 と 1 で止める（中心を過ぎたら正面のまま）
- `angleForScroll(progress)`: 0 で `ENTRY_TILT`、1 で正面。間は **`easeInCubic`**（`1 − p³` の割合で斜めが残る）。**残りの割合が `SNAP_REMAINING`（0.005）未満なら正面ちょうど**（後述）
- `decayTilt(tilt, dt, target)`・`isAtRest(tilt, target)`: 戻る先を指定できるようにした（既定は正面）

`apps/landing/js/phone3d.mjs`:

- `scroll` は `passive`。1 フレームに 1 回だけ角度を出し直す（rAF でまとめる）。節が見えている間だけ。**角度が変わらなければ描き直さない**（中心を過ぎて正面のままスクロールしている間など。R の記録 1）
- 止まっていればその角度で描き、ドラッグの後に戻っている途中なら戻る先だけを変える。ドラッグの間はスクロールの角度を使わない
- 離したら、正面ではなく**スクロールの位置で決まる角度へ**戻る
- 動きを減らす設定なら、戻る先はいつも正面（最初から正面・スクロールに合わせて動かさない）
- 本体が読めた時点の角度もスクロールの位置から（節の手前なら斜めで始まる）

## 始めの角度の向き

**`ENTRY_TILT = { x: −0.14, y: +0.44 }`**（約 8°・約 25°）。y・x の符号の 4 通りを正面の位置でドラッグして撮って見比べた（`directions.png`。左から y+x−・y−x+・y+x+・y−x−。`scripts/direction.mjs`）。1 枚目（y +・x −）: 画面が右の説明文の方を向き、左の側面と音量のボタンが見え、上の縁が少し奥へ倒れる。定義は #475 でこの符号に合わせた。

## 曲線（#475 で easeInCubic）

ステージの高さ（791px）がビューポート（900px）に近いので、「全体が見えた位置」（上端 109px）と「中心が中央」（54.5px）は 55px しか違わない。最初の版（easeOutCubic）では半分ほど見えた頃にはほぼ正面で、斜めが見えるのは入ってくる最初だけだった。A が easeInCubic に決めた。y の角度（1280×900）:

| ステージの上端 | 見えている量 | easeInCubic（今） | （最初の版の easeOutCubic） |
|---|---|---|---|
| 820px | 上の 80px | 25.2° | 18.7° |
| 600px | 上の 300px | **24.1°** | 6.8° |
| 300px | 600px | **16.2°** | 0.6° |
| 109px | 全部 | **4.5°** | 0.0° |
| 54.5px（中心） | 全部 | **0°** | 0° |

テスト（`phone3d-tilt.test.ts`）でこの値（600px で約 24°・全部見えて約 4.5°・中心で 0）を固定した。

## 正面ちょうどに丸める理由（と、easeInCubic でも効くこと）

中心の位置（上端 54.5px）は画素に丸めると 55px になり、進み具合がわずかに 1 に届かない（55px で p = 0.99941）。角度が 0 でないと iframe が 3D の変形のままになり、追補 2 の画質の対応（正面で止まっている間は 2D の変形）が効かずに文字がにじむ。残りが 0.5% 未満（0.13° 未満）なら正面ちょうどにした。easeInCubic の残りは `1 − p³` なので、p > ∛0.995 = 0.99833（上端 56.4px より上）で正面に丸まる。55px の残りは 0.00177 で、丸まる（R の「余裕が小さい」への答え: 中心から約 1.4px の幅）。`scroll-tilt.mjs` で、上端 55px で iframe の変形が `matrix(…)`（2D）であることを確かめた。
