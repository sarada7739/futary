# 030: アプリアイコンと favicon を差し替える — 人間の実機確認

iPhone Safariの「ホーム画面に追加」はB（自動化）では触れないため
（`CLAUDE.md`・タスク定義「確認観点」）、人間に確認をお願いします。

## 確認してほしい項目

1. **iPhoneのSafariで本番URL（`/app/`側。トップページから「はじめる」
   または「デモを見る」で入った先）を開き、共有メニューから
   「ホーム画面に追加」する**
2. **追加されたアイコンが、スクリーンショットではなく今回のハート型
   アイコンになっているか**（iOSはapple-touch-iconが無いとページの
   スクリーンショットを使う。それが起きていないかの確認）
3. **アイコンの四隅に、白い欠けや変な切れ方が出ていないか**
   （角丸の半径がiOSのマスクと合っていない場合にここに出る。
   角を自分で丸めず正方形のまま渡しているため、出ないはず）
4. **ホーム画面のアイコンをタップして開いたとき、上部にSafariのアドレス
   バー（枠）が残っているか**（`display: browser`にしており
   `standalone`にしていないため、残るはず。枠が消えて全画面になって
   いたら想定と違う）
5. **その状態でGoogleログインを試し、ログインが最後まで通って
   アプリに戻ってくるか**（枠が消えるとログインの遷移が別の入れ物へ
   飛んで戻ってこないことがあるため、変えていないことの確認）
6. ブラウザのタブに出るアイコンも、ハート型アイコンになっているか
   （`/`・`/app/`の両方）

## 既知の制約

- Androidネイティブ用のアイコン（`apps/app/assets/android-icon-*.png`）は
  今回のタスクの範囲外で、触れていない（背景色がブランドと合っていない
  ままだが、Androidネイティブは出していないため実害なし）
- ネイティブアプリ（iOS App Store配布）向けの`icon.png`は正方形版に
  差し替えたが、現状Webしか公開していないため実際には使われていない
